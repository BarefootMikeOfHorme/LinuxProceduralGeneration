# VaultMind Forge (LPG)

A modular system for Linux Procedural Generation focusing on asset synthesis, diffusion pipelines, semantic control, packaging, monitoring, validation, versioning, and lineage tracking.

## Modules
- forge_agent
- forge_diffusion
- forge_sr
- forge_video
- forge_semantic
- forge_packaging
- forge_monitor
- forge_validator
- forge_versioning
- forge_cli
- forge_lineage
